## `04 / ENGINEERING PRINCIPLES`

> A demo proves that something can work. Evaluation helps establish how well it works.

- Build before claiming.
- Measure before comparing.
- Understand limitations instead of hiding them.
- Prefer reproducible results over impressive-looking claims.
- Design for real constraints, not just ideal conditions.
